# pitangas_plot

pitangas_plot is a plotting tool for time series, made by Mateus Rodrigues. It opens CSV, Excel, MATLAB and HDF5 files and shows their signals in plots.

## Download

Download the zip of your system from the [latest release](https://github.com/materodr/pitangas_plot_release/releases/latest): macOS (Apple Silicon), Windows (64-bit) or Linux (64-bit). Unzip it: it makes one folder, with the app, sample files in `files_for_test` and tutorial videos in `tutorial_videos`.

## Report a bug or suggest a feature
